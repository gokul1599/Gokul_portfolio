01

THE PROBLEM & PRODUCT STORY

Personal daily organization is chronically fragmented across disconnected calendar apps, standalone to-do lists, manual expense notes, and browser bookmarks. Switching constantly between five single-purpose apps creates cognitive clutter and daily context switching friction.

I engineered LifeHub as a single-pane personal operating system: a unified environment where a user can glance at their day's schedule, log an expenditure, check upcoming deadlines, check local weather, and review habit momentum in under 30 seconds.

03

SYSTEM ARCHITECTURE

LAYER 01

Client Layer (React 19)

Built with React 19 and Vite for instant hydration and responsive tab navigation across desktop and mobile form factors.

LAYER 02

State Store (Zustand 5)

Decoupled atomic store providing granular subscriptions so individual cards (schedule list, expense bar, clock) render independently.

LAYER 03

Offline Persistence

Offline-first LocalStorage and IndexedDB synchronization ensuring zero data loss during network hiccups or mobile subway commutes.

LAYER 04

Telemetry & Alerts

Open-Meteo weather API integration, HTML5 Audio reminder chimes, and browser notification permission controls.

04

ENGINEERING DECISIONS

Why React 19 + Vite?

Fast startup time and lightweight bundle sizes were essential for a daily workspace. Vite enables instant HMR during development and sub-100KB gzipped production builds.

Why Zustand 5 over Redux?

Redux introduces unnecessary boilerplate for client-centric single-user dashboards. Zustand gives immutable state updates with tiny bundle footprint and effortless persistence middleware.

Tailwind CSS v4 Design Tokens

Utilized Tailwind v4 CSS variables for dark-mode obsidian themes, fluid typography clamping, and micro-spacing consistency.

Polite Audio Chimes & Notifications

Avoided jarring default system beeps. Crafted soft harmonic synthesized tones played via the Web Audio API with user-initiated audio context unlocking.

05

CHALLENGES & LESSONS LEARNED

CHALLENGE

High-frequency state updates (a live ticking second clock and weather poll) caused unnecessary re-renders of heavy schedule and chart lists.

SOLUTION

Isolated the digital clock and date greeting into an independent leaf component subscribed only to a dedicated millisecond timer, bypassing the main dashboard tree.

LESSON

Clean component boundaries are not just an aesthetic preference — they are critical for maintaining smooth responsiveness on mobile devices.
